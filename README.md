# Szymon Machnio — Portfolio fotograficzne

Minimalistyczna strona portfolio z animacją blur-to-sharp przy każdym wejściu.

## Uruchomienie lokalne

```bash
# Python
python3 -m http.server 8080

# lub Node.js
npx serve .
```

Otwórz [http://localhost:8080](http://localhost:8080).

## Funkcje

- Responsywny layout na wszystkich urządzeniach
- Tło kostne z lekkim szumem
- Animacja ładowania: blur → ostrość
- Przełącznik motywu jasny / ciemny
- Nawigacja: Works, About me, Contact + Instagram
